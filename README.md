# HomeLab Security Audit
# Project Overview
This project will document an ongoing assessment of my personal homelab environment.

I am currently studying a bachelor of Information Technology, majoring in cybersecurity at QUT.

The purpose of this assessment is to identify potential security risks in my existing infrastructure, evaluate my current security controls, and develop practical recommendations to improve its security.

I aim to apply both technical security practices and recognised cybersecurity frameworks to a real environnment.

# Assessment Objectives
- Identify and document hardware, software and network assets.
- Review existing security configurations and controls.
- Identify vulnerabilities, threats and potential risks.
- Evaluate risks based on likelihood and impact.
- Recommend and priorities improvements.
- Implement security controls where practical.
- Document findings, remediation and lessons learned.

# Environment 
The assessment covers my self hosted homelab, including:
- Ubuntu Linux server
- Docker containers and applications
- Router and network switch
- DNS filtering (PiHole)
- Security monitoring (Wazuh)
- Network connected devices and services

# Assessment Methodology
This assessment will follow this process:
1. Scope and Asset identification
2. Security Review
3. Risk Assessment
4. Recommendations
5. Implementation and Validation
6. Reporting
The assessment will draw from relevant guidance such as the ACSC Essential Eight, the ASD Information Security Manual, and ISO/IEC 27001 and 27005 when applicable.

# Current Progress
The assessment is current in its initial documentation and planning stage. 
Findings, recommendations and validation evidence will be added as the assessment progresses.
